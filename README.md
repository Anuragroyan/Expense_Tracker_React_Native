💰 Expense Tracker

Expense Tracker is a React Native Expo application designed to provide a clean and interactive interface for managing daily expenses. The application allows users to add new expenses, view recent spending activity, and manage existing expense records through a simple and user-friendly interface.

✨ Key Features

* ➕ Add Expense – Add new expense records with details such as title, date, and amount.
* 🕒 Recent Expense – View expenses from the last 7 days for quick tracking of recent spending.
* 🧾 Manage Expense – View, update, and delete existing expense records.
* 📱 Clean and responsive React Native UI
* 🧭 Simple and intuitive navigation
* 📝 Easy-to-use expense management interface

🏗️ Architecture & Workflow

The React Native Expo application provides the user interface for managing expense records.

Users can add an expense by entering details such as the title, date, and amount. Newly added expenses are displayed within the application and can be reviewed through the Recent Expense section.

The Manage Expense section allows users to view, update, and delete their existing expense records.

Expense Tracker → Add Expense → Recent Expense (Last 7 Days) → Manage Expense (View • Update • Delete)

🛠️ Tech Stack

React Native • Expo • JavaScript • React Hooks • Responsive UI • Form Management • Mobile Navigation

▶️ Run the App

1. Clone the repository

git clone <repository-url>
cd expense-tracker

2. Install dependencies

npm install

3. Start Expo

npx expo start

4. Run on Android

npx expo start --android

5. Run on iOS

npx expo start --ios

6. Run on Web

npx expo start --web

Note: This version focuses on the frontend UI and user experience and does not require a backend or database.
