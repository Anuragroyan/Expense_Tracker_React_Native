💰 Expense Tracker

Expense Tracker is a React Native Expo application designed to help users manage their daily expenses using Firebase as the backend database. Users can create, view, update, and delete expense records while tracking important details such as title, date, and price. Recent expenses are displayed for quick and convenient financial tracking.

✨ Key Features

* 💰 Track daily expenses
* ➕ Add new expense records
* 👁️ View expense details
* ✏️ Edit existing expenses
* 🗑️ Delete expenses
* 📝 Store expense title and details
* 📅 Track expense dates
* 💵 Record expense prices
* 🕒 Display recent expenses
* 🔄 Real-time Firebase data synchronization
* ☁️ Cloud-based data persistence
* 📱 Clean and interactive React Native UI

🏗️ Architecture & Workflow

The React Native Expo application provides the user interface for creating and managing expense records, while Firebase handles cloud data storage and synchronization. Users can add expenses with details such as title, date, and price, then view, edit, or delete their records.

Recent expense data is retrieved from Firebase and displayed in the application, allowing users to quickly review their latest spending activity.

🛠️ Tech Stack

React Native • Expo • JavaScript • Firebase • Cloud Firestore • CRUD Operations • Real-Time Data Synchronization

▶️ Run the App

1. Install dependencies

npm install

2. Start Expo

npx expo start

3. Run on Android

npx expo start --android

4. Run on iOS

npx expo start --ios

5. Run on Web

npx expo start --web

🎯 Project Purpose

This project demonstrates how to build a cloud-connected expense management application using React Native, Expo, and Firebase. It provides practical experience with CRUD operations, Firebase database integration, cloud data persistence, real-time data handling, form management, and building a simple mobile application for tracking personal expenses.
